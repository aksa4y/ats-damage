# Будущие ассеты

Повреждённые игровые материалы не входят в проект. Нужны авторские diffuse/base-color, normal и при необходимости emissive/mask текстуры для конкретных UV и shader parameters. Разбитый силуэт потребует отдельного mesh. Форматы и пути определяются после выбора модели, версии ATS и реализации backend. См. ../docs/VISUAL_BACKEND.md.
